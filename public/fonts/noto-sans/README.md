# Noto Sans para PDFs

Fontes oficiais do [Noto Fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), usadas para conservar acentos e caracteres nos PDFs municipais. Regular e Bold foram obtidas dos arquivos `hinted/ttf/NotoSans/NotoSans-Regular.ttf` e `NotoSans-Bold.ttf` do repositório. Licença SIL Open Font License 1.1 incluída neste diretório.

As fontes e o gerador de PDF são carregados no navegador somente quando o usuário solicita o download. Não há consulta adicional ao TSE para produzir o documento: os dados exibidos no cartão são copiados no instante do clique.
